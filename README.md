# 🍕 Pizza Sales Analysis Using SQL

## 📌 Project Overview

This project analyzes **pizza sales data using SQL** to understand sales performance, customer preferences, and overall business trends.

The analysis uses SQL queries to extract useful insights from the sales data and answer important business questions.

## 🎯 Objectives

The main objectives of this project are to:

* Analyze overall pizza sales
* Find the total number of orders and pizzas sold
* Identify the most popular pizzas
* Analyze sales by pizza category and size
* Find the best and worst-selling pizzas
* Understand daily and monthly sales trends
* Identify which pizzas generate the highest revenue

## 🗂️ Dataset

The dataset contains information about pizza orders and includes details such as:

* Order ID
* Order Date
* Order Time
* Pizza Name
* Pizza Category
* Pizza Size
* Quantity
* Price

## 🛠️ Tools Used

* **SQL** – Data analysis and querying
* **MySQL** – Database management and execution of queries
* **GitHub** – Project documentation and version control

## 🔍 Key Analysis

The SQL queries in this project cover the following areas:

### 1. 📊 Overall Sales

* Total revenue
* Total orders
* Total pizzas sold
* Average order value
* Average pizzas per order

### 2. 🍕 Pizza Performance

* Best-selling pizzas
* Least-selling pizzas
* Pizzas generating the most revenue
* Pizzas with the highest quantity sold

### 3. 📦 Category Analysis

* Sales by pizza category
* Revenue generated by each category
* Quantity sold by category

### 4. 📏 Size Analysis

* Sales by pizza size
* Popular pizza sizes
* Revenue generated by each size

### 5. 📅 Time-Based Analysis

* Daily order trends
* Monthly sales trends
* Busiest days and months
* Number of orders over time

## 💡 Key Insights

The analysis helps answer questions such as:

* Which pizza is the most popular?
* Which pizza category generates the most revenue?
* What is the most commonly ordered pizza size?
* Which day has the highest number of orders?
* Which month generates the highest sales?
* Which pizzas are performing poorly?
